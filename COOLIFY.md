# Coolify deployment

## Nixpacks Node.js deployment

- Build Pack: Nixpacks
- Base Directory: `/`
- Build Command: `npm run build`
- Start Command: `npm start`
- Is it a static site?: disabled
- Ports Exposes: `3000`
- Domain container port: `3000`

## Dockerfile deployment

- Build Pack: Dockerfile
- Dockerfile Location: `./Dockerfile`
- Port: `80`

After deployment, submit `https://8kstrongiptv.cc/sitemap.xml` in Google Search Console and request indexing for each canonical URL.

Public page URLs do not contain `.html` and do not end with `/`, for example `https://8kstrongiptv.cc/reseller`.
